# Telar

Blog estático en español sobre IA y automatización, optimizado para ser citado por chatbots.

```bash
npm run check   # valida artículos y páginas
npm run build   # genera dist/
```

Sin dependencias: solo Node 20 o superior. Guía de operación en `docs/OPERACIONES.md`; instrucciones para agentes en `CLAUDE.md`.
