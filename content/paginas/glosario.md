## Términos

### GEO (Generative Engine Optimization)
Conjunto de prácticas para que los motores de búsqueda con IA generativa, como ChatGPT Search, Perplexity, Claude y Google AI Overviews, usen tu contenido como fuente al responder.

### AEO (Answer Engine Optimization)
Término cercano a GEO. Se centra en optimizar contenido para que sea elegido como respuesta directa por buscadores y asistentes.

### LLMO
Sigla de optimización para modelos de lenguaje. Se usa como sinónimo de GEO en algunos textos.

### Motor de búsqueda generativo
Sistema que responde una consulta redactando una respuesta propia a partir de varias fuentes, y suele mostrar de dónde sacó la información.

### RAG (generación aumentada por recuperación)
Técnica en la que un modelo de lenguaje recupera documentos externos antes de responder, para apoyarse en información actual y citable.

### Rastreador de IA
Programa automático que visita páginas web para recopilar contenido. Algunos sirven para entrenar modelos, otros para buscar o para actuar a pedido de una persona.

### robots.txt
Archivo en la raíz de un sitio que indica a cada rastreador qué puede visitar. Es una petición voluntaria, no un bloqueo técnico.

### llms.txt
Propuesta de la comunidad de un archivo Markdown que resume las páginas importantes de un sitio para modelos de lenguaje. No es un estándar oficial.

### sitemap.xml
Archivo que lista las páginas de un sitio para que los buscadores las encuentren.

### Datos estructurados (schema.org)
Marcado en el código de una página que describe su contenido de forma que las máquinas lo entienden: artículo, preguntas frecuentes, organización.

### FAQPage
Tipo de dato estructurado que marca una página con preguntas y respuestas.

### Tasa de citación
Porcentaje de consultas de una lista en las que un motor de IA cita tu sitio como fuente.

### Desvío (deflection)
En atención al cliente, porcentaje de conversaciones que no llegaron a un agente humano. No equivale a resolución: incluye a quien se rindió.

### Programa de afiliados
Acuerdo por el cual una empresa paga una comisión a quien le envía clientes mediante un enlace propio.

### Comisión recurrente
Pago periódico que recibe el afiliado mientras el cliente referido siga suscrito, durante un plazo definido o de por vida.

### Cookie de afiliado
Archivo que registra qué enlace llevó al usuario a la tienda. Su duración define cuántos días tiene el afiliado para recibir comisión después del clic.

### Contenido patrocinado
Contenido pagado por una marca. Debe marcarse como tal de forma visible.

### Automatización
Uso de software para ejecutar tareas repetitivas sin intervención manual, por ejemplo copiar datos entre aplicaciones o clasificar correos.

## Preguntas frecuentes

### ¿Cuál es la diferencia entre GEO y SEO?

El SEO busca posicionar una página en una lista de resultados. GEO busca que un motor de IA use tu contenido como fuente dentro de su respuesta.

### ¿GEO y AEO son lo mismo?

En la práctica se usan como sinónimos. Cambia el énfasis del nombre, pero las técnicas se solapan casi por completo.
